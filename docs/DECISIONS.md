## 关键理由补充

- **ADR-004/005**：insightface 官方模型包（buffalo_l）单文件即可获得检测+性别+特征三件套，质量经过大规模验证；MTCNN（facenet-pytorch 导出 ONNX）作为对照以防 SCRFD 在特定素材上表现异常。
- **ADR-006**：SCUT-FBP5500 是最常用的公开颜值数据集（5500 人、5 分制、多人标注），训练回归头的成本低（MobileNet/ResNet backbone，CPU 可推理）；输出 1-5 分线性映射 0-100。
- **ADR-007**：需求是"一个视频可形成多张有明显区别的面容"，视频内聚类即可满足；跨视频同人合并引入身份漂移风险，列为扩展。
- **ADR-011**：预计单机使用，处理吞吐瓶颈在 ffmpeg 与 CPU 推理，单 worker 串行已足够，且显著降低断点续跑的复杂度。
